# 《婦嬰新說》Sinica 1792 字形更正附錄 v0.3.1

Bodleian Sinica 1792 · 1858 上海仁濟醫館藏板本 · 曲宸宇（Chen-Yu Chu）

這份附錄整理《婦嬰新說》轉錄的第七批覆核第 33–52 項。依據館藏影像更正 14 個字位，並列出保留原讀、只註記原書數值差異與尚未定讀的案例。附錄只包含更正資料、判讀摘要及檢核檔。館方原件、掃描、裁片與全文在各自的來源和版本管理。[Bodleian 館藏目錄](https://digital.bodleian.ox.ac.uk/objects/81ca8c5b-9a4c-4da0-83b9-ed8bc4bc0988/)

## 核對與套用

- `corrections.json` 列出每個字位的單元 ID、從零起算的 Unicode 碼點位置、原讀、新讀及館藏對應頁。
- 請先確認 v0.3.0 的 `book.json` SHA-256 等於 `c0e01287f848b98f92d79eb69c0beefbcf9a79dd54725a8c62305eee4ac0b92e`。每筆操作到 `units` 找到 `id` 等於 `unit_id` 的唯一單元，核對 `page_id`，確認 `text` 在指定位置等於 `from`，再將該碼點替換為 `to`。校驗不符時整批停止。
- 各操作皆為單碼點替換，全文長度及其他位置保持原狀。套用應另存衍生檔，保留引用基準、附錄版本及原檔校驗碼。TXT、TEI 及其他匯出留在 v0.3.0 版。
- `corrections.schema.json` 定義附錄格式，`SHA256SUMS` 用於檢核附錄內的說明與兩份 JSON。發布前已對 v0.3.0 固定基礎檔驗證前值、套用差異及逆操作。
